STRATEGIC QAT

Professional Information Architecture

NurseLink should be tested as more than a membership-registration portal if it is expected to support the future Professional Information System for Returned and Returning OFW Nurses (PIS-RON).

Professional Identity → Nursing / Healthcare Qualifications → Overseas Employment History → Current Migration Status → Reintegration Status → Current Employment → Skills & Specialization → SPINB / Philippine Employment Interest → Kapatiran Membership → Consent / Data Governance
Important architecture check

A system designed primarily around membership registration may work correctly as a registration portal while still being structurally inadequate as a future professional information and workforce planning system.

MIGRATION CLASSIFICATION

Do Not Reduce OFW Status to a Binary Field

The data model should distinguish meaningful workforce and reintegration states rather than simply OFW / Former OFW.

Currently Overseas Returning Soon Recently Returned Permanently Returned Re-employed in Philippine Healthcare Working Outside Healthcare Entrepreneur / Self-employed Retired Seeking Employment Interested in SPINB

These classifications can support future workforce planning and collaboration with KNMONP, DMW-NRCO, DOH and other authorized stakeholders, subject to appropriate consent, purpose limitation and data-sharing governance.

RECOMMENDED QAT WORKFLOW

Screen-by-Screen Registration Review

1. Capture Review every registration page or step from first screen to final submission.
2. Classify Record each finding as Critical, Major, Moderate or Minor.
3. Specify Document the problem, expected behavior and recommended correction.
4. Improve data Identify missing fields, classification gaps and future PIS-RON requirements.
5. Review UX Assess instructions, mobile usability, accessibility and workflow clarity.
6. Re-test Verify corrected behavior before closing the QAT finding.
Priority: Critical — Must fix High — Important Medium — Should fix
